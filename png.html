PNG

PNG (Portable Network Graphics) adalah format gambar berbasis raster (piksel). Artinya gambar tersusun dari titik-titik kecil. Kelebihan utama PNG adalah kualitasnya tidak menurun karena menggunakan lossless compression (kompresi tanpa kehilangan data). Selain itu, PNG mendukung transparansi, sehingga sering dipakai untuk logo, ikon, atau desain dengan latar belakang transparan. Kekurangannya, ukuran file biasanya lebih besar dibanding JPG.
